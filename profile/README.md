# GameGene

**Sourced game design history for game developers and their AI agents.**

[GameGene](https://gamegene.app/about?utm_source=github-org&utm_medium=profile) records which games faced a design call, what their developers chose, why, and what they gave up, each traced to a talk, interview or postmortem. A developer's own statement is kept apart from a critic's reading, and "not on record" is said plainly instead of guessed.

## What's here

| Repository | What it is |
|---|---|
| [**game-genre-playbooks**](https://github.com/gamegene-app/game-genre-playbooks) | A free skill for AI agents: genre-by-genre design calls with developers' answers and what they cost. Roguelites, horror, cozy games and life sims, plus calls that cross genres. One line to install in Claude Code |
| [**gamegene-mcp**](https://github.com/gamegene-app/gamegene-mcp) | The GameGene MCP server: read the records from Claude, ChatGPT, Claude Code, Codex or VS Code while you work. How to connect, and where to report problems |

## Asking for more

- **A game or a design question that isn't on record yet**: [send a research request on GameGene](https://gamegene.app/feedback?panel=submit&utm_source=github-org&utm_medium=profile). It goes straight into the research queue.
- **A new genre or question for the playbooks**: open an issue in [game-genre-playbooks](https://github.com/gamegene-app/game-genre-playbooks/issues/new/choose).
- **A bug or an idea for the MCP tools**: open an issue in [gamegene-mcp](https://github.com/gamegene-app/gamegene-mcp/issues/new/choose).
